# FitZone — Fitness & Wellness Landing Page

A modern, responsive, bilingual fitness and wellness landing page built with HTML, CSS, and JavaScript.

This project demonstrates front-end web development skills through a fitness business website concept.

## Live Demo

[View Live Website](https://ratthaphum2583-prog.github.io/fitzone-landing-page/)

## Features

- Modern dark-themed design with purple and blue gradients
- Responsive layouts for desktop, tablet, and mobile
- Thai and English language switching
- Language preference persistence using localStorage
- Mobile hamburger navigation
- Seven landing page sections
- Contact form with HTML5 validation
- Interactive navigation and social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser localStorage
- Git & GitHub
- GitHub Pages

## Website Sections

1. Home
2. Services
3. About Us
4. Trainers
5. Call to Action
6. Contact
7. Footer

## Contact Form

The contact form is a demonstration feature.

It includes HTML5 form validation and JavaScript submit handling. It does not send emails or store submitted information.

## Project Purpose

FitZone was developed as a portfolio project to demonstrate the ability to create a modern, responsive, and interactive business landing page.
